# 测试、功能范围与限制

## 测试

```sh
make unit-test  # 不依赖XC8
make test       # 单元测试 + XC8真实固件端到端测试
```

端到端测试会向GP3注入一次按下/松开事件，验证GP0/GP1两颗LED反转，
并检查GP2产生约50ms的蜂鸣器脉冲。

## 已实现

- PIC10F200 Baseline 12位指令译码；
- W、PC、STATUS、FSR、PCL和两级硬件栈；
- 16字节RAM与INDF/FSR间接寻址；
- 跳转、调用、返回、计算跳转和跳过周期；
- GPIO/TRIS、GP3仅输入、读-修改-写行为；
- 弱上拉、外部引脚驱动和引脚变化唤醒；
- Timer0内部/外部时钟、边沿、预分频和写入抑制；
- WDT、Sleep、POR、MCLR及WDT复位；
- Intel HEX和配置字加载；
- 反汇编、跟踪、断点、转储、事件和VCD；
- JSON电路、SDL可视器件及STM32 GPIO桥接。

## 当前限制

- 只支持PIC10F200；
- 不模拟器件电压、温度、振荡误差等模拟特性；
- MCLR尚未作为完整的异步电路端点；
- 没有ELF/DWARF源码级调试；
- 没有条件断点、观察点或可视拖拽编辑器；
- JSON走线指令和多端点公共网络尚未完整实现。

传统PIC的指令周期频率通常为 `Fosc/4`。内部振荡器为4MHz时，一个
指令周期约为1微秒。
