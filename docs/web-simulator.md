# Web 电路仿真器

Web 前端提供一个类似 SimulIDE 的本地电路实验台。它没有重新实现一套 PIC
解释器，而是通过本地服务调用项目现有的 C 核心，因此命令行、SDL 和 Web
执行的是同一套指令逻辑。

## 启动

Linux/WSL 需要 Node.js、GCC、Make 和 XC8。Windows PowerShell 启动脚本
会调用 WSL 中的统一构建流程，因此 Windows 侧还需要可用的 `wsl.exe`。
在项目根目录执行：

```powershell
.\frontends\web\scripts\start.ps1
```

启动时会构建 Web 后端和全部示例固件，然后访问
`http://127.0.0.1:4173`。可以指定初始示例和端口：

```powershell
.\frontends\web\scripts\start.ps1 -Example breathing_led -Port 8080
```

Linux 是启动流程的主入口：

```sh
./frontends/web/scripts/start.sh --example button --port 4173
```

也可执行 `make run-web EXAMPLE=button`。PowerShell 脚本只把参数转交给这个
Linux 脚本，不再单独维护构建和启动步骤。

## 使用

- 从左侧器件库把 PIC10F200、PIC10F202、LED、按键、蜂鸣器或 W25Q Flash
  拖到画布。
- 点击一个引脚，再点击另一个引脚完成连线。
- 拖动器件可以调整位置；右侧“器件”页可修改 ID 和 LED 颜色。
- 鼠标滚轮以指针位置为中心缩放，中键按住可向四个方向平移整个画布。
- 在空白处按住鼠标左键可框选多个器件；选中后可整体拖动或批量删除。
- `Ctrl`/`Shift` 点击器件可以向当前多选集合增加或移除器件。
- 编辑器内部使用 12000×8000 的大型虚拟画布和居中原点；JSON 仍保存原有
  世界坐标，因此不会影响 SDL 共用电路。
- 器件坐标和布线拐点以半格（10 px）为吸附步长。
- 外设端子的高度会匹配所连接 PIC 引脚的半格相位，所以移动一个网格后能够
  得到完全水平的连线。
- “适应”会自动缩放并居中全部器件；打开电路时也会自动执行一次。
- 单击连线后可用“删除选中”或 `Delete` 删除，`Esc` 可取消正在进行的连线。
- 按键既可以按住产生输入，也可以像其他器件一样拖动。
- 选择或操作器件只更新隐藏的器件属性内容，不会强制离开正在观察的 CPU、
  RAM 或程序页签；拖动时坐标字段实时更新。
- 选中 PIC 后，在“器件”页为该芯片单独设置 HEX；固件属于 MCU 实例，不是
  整个页面的全局属性。
- 一个电路可以包含多颗 PIC。Node 服务按器件 ID 管理独立 C 后端，运行时所有
  已加载芯片一起推进；寄存器、程序、断点和单步对应当前选中的芯片。
- 运行、暂停、单步和复位按钮控制 CPU。
- 右侧面板实时显示寄存器、状态位、硬件栈、RAM，以及带反汇编文本的程序
  Flash；当前 PC 对应的指令会高亮。“跟随 PC”默认开启，运行和单步时会自动
  将当前指令滚动到程序面板中央。
- 单击程序指令可设置或取消断点。断点在 C 核心中于指令执行前精确命中，再次
  运行会越过当前断点后继续。
- CPU 面板和芯片引脚会同时显示 GP0～GP3 的输入/输出方向及实时高低电平。
- 电路编辑支持 `Ctrl+Z` 撤销、`Ctrl+Y` 重做，最多保留 100 个状态。
- 每次电路编辑都会自动保存到浏览器本地；“恢复草稿”可重新加载最近状态。
- 按住画布上的按键会向连接的 PIC GPIO 输入低电平。
- 打开项目示例并编辑后，使用“保存电路”直接写回原来的 `diagram.json`。

## W25Q SPI Flash

Web 中的 W25Q 使用共享 C 器件模型，当前支持 SPI Mode 0 的 `0x03`
连续读取、`0x06` 写使能、`0x02` 页编程、`0x05` 状态寄存器读取和
`0x9F` JEDEC ID 命令。把四个信号连接到同一颗 PIC：

| W25Q 引脚 | 含义 |
|---|---|
| `/CS` | 低电平片选 |
| `CLK` | SPI 时钟 |
| `DI` | 主控输出、Flash 输入（MOSI） |
| `DO` | Flash 输出、主控输入（MISO） |

选中 W25Q 后，右侧“器件”面板可以：

- 在 W25Q10（128 KiB）到 W25Q128（16 MiB）之间选择容量；
- 在输入框填写十六进制字节，点击“写入”后从地址 0 开始更新内容；
- 按地址跳转、翻页或刷新，以十六进制和 ASCII 实时查看 256 字节数据。

选中 W25Q 时，数据查看器每 200 ms 从 C 器件模型重新读取当前页；无论数据由
PIC 固件的 SPI 命令还是属性面板写入，都会自动显示，不需要手动刷新。修改容量
会重新创建虚拟 Flash。容量与地址 0 的配置数据分别保存在器件的
`attrs.capacity` 和 `attrs.data` 中。例如：

```json
{
  "id": "flash",
  "type": "w25q",
  "left": 650,
  "top": 180,
  "attrs": {
    "capacity": 2097152,
    "data": "50 49 43 45 4D 55 21"
  }
}
```

完整可运行电路见 `examples/spi_flash/diagram.json`。当前每个 MCU 后端挂载一颗
W25Q。页编程遵守 NOR Flash 只能把位从 1 改成 0 的约束；扇区擦除、忙状态
延迟和数据持久化将在后续扩展。

## 与 SDL 共用电路文件

Web 直接读取 `examples/*/diagram.json`，主要字段保持一致：

```json
{
  "version": 1,
  "clockHz": 4000000,
  "firmware": "examples/button/build/firmware.hex",
  "parts": [],
  "connections": []
}
```

器件坐标、属性和连接都会原样保留。顶层 `firmware` 字段用于兼容旧版单主控
电路；Web 与 SDL 都会优先读取每颗 MCU 的 `attrs.firmware`，因此同一张电路
可以放置多颗运行不同HEX的主控。纯界面属性也应放入器件的 `attrs` 对象中。

为兼容已有 SDL 示例，坐标约定是：

- PIC 的 `left/top` 表示芯片矩形左上角；
- LED、按键和蜂鸣器的 `left/top` 表示器件中心；
- 两端统一使用 MCU 300×240、LED 直径48、按钮110×60、蜂鸣器直径60；
- Web 在100%缩放下与SDL使用相同器件尺寸和世界坐标；Web连接圆点贴近
  芯片边缘，并会让外设端口自动朝向所连接的器件。

## 架构

```text
浏览器编辑器
    │ HTTP / JSON
本地 Node 服务
    │ stdin / stdout
picemu-web-core（C）
    │
PIC10 CPU、HEX 加载器、器件描述
```

Node 服务只监听 `127.0.0.1`。用户上传的 HEX 按 MCU ID 暂存在
`build/web/uploads/<mcu-id>.hex`，执行 `make clean` 会将其删除。
“保存电路”只能写入当前从项目示例列表打开的 JSON，不会把浏览器任意路径
直接交给文件系统。

## 当前范围

当前支持 PIC10F200、PIC10F202、LED、按键、无源蜂鸣器和基本读写命令范围内
的 W25Q。
连线模型目前针对“一根 GPIO
连接一个简单外设”，尚未实现电阻、电源网络、模拟电压、总线和复杂电气冲突。
新增芯片或器件时，应分别扩展共享仿真设备层和 Web 的外观/交互层，不应在页面
里加入针对某个示例固件的特殊逻辑。
