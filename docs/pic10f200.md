# PIC10F200引脚与功能

## 6引脚SOT-23封装

```text
             PIC10F200
         ┌─────────────┐
 GP0  1 ─┤             ├─ 6  GP3/MCLR/VPP
 VSS  2 ─┤             ├─ 5  VDD
 GP1  3 ─┤             ├─ 4  GP2/T0CKI/FOSC4
         └─────────────┘
```

| 脚号 | 名称 | 方向 | 功能 |
|---:|---|---|---|
| 1 | GP0/ICSPDAT | 输入/输出 | GPIO、ICSP编程数据 |
| 2 | VSS | 电源 | GND |
| 3 | GP1/ICSPCLK | 输入/输出 | GPIO、ICSP编程时钟 |
| 4 | GP2/T0CKI/FOSC4 | 输入/输出 | GPIO、Timer0外部时钟、FOSC/4 |
| 5 | VDD | 电源 | 正电源 |
| 6 | GP3/MCLR/VPP | 仅输入 | GPIO输入、低有效复位、编程电压 |

## TRISGPIO

低4位依次控制 GP0～GP3，`1`表示输入，`0`表示输出。GP3是例外：
硬件上始终只能输入，即使将bit 3写成0也不能输出。bit 4～7没有对应引脚。

```c
TRISGPIO = 0b111000; /* GP0、GP1、GP2输出，GP3输入 */
```

PIC10F200没有GP4、GP5、GP6，也没有ADC、PWM、UART、SPI或I²C。
PIC10F204/206具有额外的模拟比较器，不能把其功能当作PIC10F200功能。
