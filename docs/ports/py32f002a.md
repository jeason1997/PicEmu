# PY32F002A 裸机端口

该端口在 PY32F002A（32 KB Flash、4 KB SRAM）上运行与命令行和 Web 端相同的
PIC10 C 核心。PIC 固件在构建时从 Intel HEX 转换为只读 C 数组，不需要修改平台
入口即可切换示例。端口需要的 CMSIS、PY32 设备头、启动文件和链接脚本已经放在
`ports/py32f002a/vendor/`，不依赖参考 Blink 工程旁边的 `Common` 目录。

## 硬件与时钟

系统时钟沿用参考 Blink 工程的配置：24 MHz HSI 经固定二倍频 PLL 得到 48 MHz，
Flash 使用一个等待周期。Cortex-M0+ 没有 DWT 周期计数器，因此端口让 24 位
SysTick 自由运行，并在每条 PIC 指令后累加实际经过的核心时钟。PIC10 默认按
4 MHz 振荡器、1 MHz 指令周期调度；若解释执行本身超过实时预算，会以芯片能够
达到的最高速度继续执行，不会跳过 PIC 指令。

默认 GPIO 映射集中在 `ports/py32f002a/include/board_config.h`：

| PIC 引脚 | PY32F002A 引脚 | 说明 |
|---|---|---|
| GP0 | PB1 | 与参考 Blink 工程 LED 引脚一致 |
| GP1 | PA1 | 通用输入/输出 |
| GP2 | PA2 | 通用输入/输出 |
| GP3 | PA3 | PIC10F200/202 上仅输入 |

板上 LED 若为低电平点亮，把对应映射的 `active_low` 改为 `1`。烧录和调试使用的
SWD 引脚未被默认映射占用。

## 构建与检查

需要 `arm-none-eabi-gcc`、GNU Make 和构建 PIC 示例所需的 XC8。工具路径从
`PATH` 获取，也可以用 `CROSS` 指定交叉工具链前缀。

```sh
# 默认构建 blink，并生成 ELF、BIN 和 HEX
make py32

# 切换其他 PIC 示例
make py32 EXAMPLE=led_chaser

# PIC10F202 固件需同时选择正确的器件容量
make py32 EXAMPLE=spi_flash DEVICE=pic10f202

# 只做交叉编译器语法检查和内嵌固件一致性测试
make py32-check EXAMPLE=blink
make py32-host-test EXAMPLE=blink
```

产物位于 `ports/py32f002a/build/<示例名>/`。也可在端口目录直接运行 `make`、
`make check`、`make host-test` 和 `make clean`。

## OpenOCD 烧录

默认使用 CMSIS-DAP。OpenOCD 自带脚本目录中需要能找到 `target/py32f002a.cfg`；
仓库内的包装配置会把 Flash 和工作区大小设为本芯片实际容量。

```sh
make -C ports/py32f002a flash EXAMPLE=blink
make -C ports/py32f002a reset
```

可通过 `OPENOCD` 指定程序路径，通过 `OPENOCD_INTERFACE` 改用其他调试器配置，
例如 `OPENOCD_INTERFACE=interface/stlink.cfg`。

## Windows PowerShell 烧录

Windows 下可从仓库根目录直接运行：

```powershell
# 在 WSL 中构建 blink，然后用 CMSIS-DAP 烧录并复位
.\ports\py32f002a\scripts\program.ps1

# 构建并烧录 PIC10F202 示例
.\ports\py32f002a\scripts\program.ps1 `
    -Example spi_flash -Device pic10f202

# 只复位芯片，不重新构建
.\ports\py32f002a\scripts\program.ps1 -Action Reset
```

脚本依次查找 `ports/py32f002a/tools/openocd/bin/openocd.exe` 和 `PATH` 中的
`openocd.exe`，并自动识别 xPack 的 `openocd/scripts` 目录。PY32F002A 目标配置
已经随端口保存，不要求 OpenOCD 安装包自带同名目标脚本。也可以显式指定参考
工程自带的 OpenOCD：

```powershell
.\ports\py32f002a\scripts\program.ps1 `
    -OpenOcd "E:\path\to\openocd\bin\openocd.exe" `
    -OpenOcdScripts "E:\path\to\openocd\scripts"
```

所用 OpenOCD 必须包含 `py32f002a` Flash 驱动和目标脚本。已有 ELF 时可传入
`-NoBuild` 跳过 WSL 构建；其他调试器可通过 `-Interface` 指定配置文件。
