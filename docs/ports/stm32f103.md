# STM32F103移植接口

PIC核心不依赖操作系统、SDL、文件系统或动态内存。STM32工程需要加入：

```text
src/core/pic_device.c
src/core/pic10_cpu.c
src/firmware/hex_loader.c
src/platform/gpio_bridge.c
include/picemu/core/pic_device.h
include/picemu/core/pic10_cpu.h
include/picemu/firmware/hex_loader.h
include/picemu/platform/gpio_bridge.h
```

推荐映射：

```text
PIC GP0 -> STM32 PA0
PIC GP1 -> STM32 PA1
PIC GP2 -> STM32 PA2
PIC GP3 -> STM32 PA3（始终输入）
```

在STM32工程中实现`PicPlatformOps`：

```c
static void stm32_set_mode(void *ctx, unsigned pin,
                           PicPlatformPinMode mode);
static void stm32_write(void *ctx, unsigned pin, bool high);
static bool stm32_read(void *ctx, unsigned pin);
static uint64_t stm32_time_us(void *ctx);
```

初始化：

```c
extern const HexImage blink_image;

Pic10Cpu cpu;
PicHardwareBridge bridge;

pic10_init(&cpu, &blink_image, &PIC_DEVICE_PIC10F200);
pic_hardware_bridge_init(&bridge, &cpu, &stm32_ops);
```

主循环根据硬件定时器累计的微秒数执行PIC周期：

```c
while (1) {
    uint32_t cycles = elapsed_microseconds();

    while (cycles-- != 0) {
        pic_hardware_bridge_sync(&bridge);
        pic10_step(&cpu);
        pic_hardware_bridge_sync(&bridge);
    }
}
```

不要在1 MHz中断中完整执行模拟器；建议使用自由运行定时器，在主循环中
批量追赶PIC周期。PIC固件可使用项目的`hex2c`工具转换为静态C数组，
避免STM32端文件系统。
