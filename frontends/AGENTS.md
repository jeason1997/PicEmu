# Web 前端通用规则

本文件适用于 Web 前端；具体实现还应遵守 `web/AGENTS.md`。

- 电路由 `diagram.json` 描述，不把示例电路写死在任一前端主程序中。
- Web 使用 `diagram.json` 保存世界坐标、器件尺寸、实例属性和连接关系。
- 容量、颜色和固件路径等属性属于具体器件实例，统一放在 `attrs` 中。
- 连线端点必须真实对应器件引脚，线路不得从器件图形下穿过而造成接错引脚的
  视觉错觉。
- 自定义布线路径只使用水平和垂直线段，拐点自动形成直角，不显示斜线。
- 外设协议和状态由共享 C 模型实现，显示层不得伪造结果。
- W25Q 等存储器查看器读取真实 C 器件模型，并在数据变化后及时更新。
