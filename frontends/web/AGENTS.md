# Web 前端规则

- Web 使用本地 Node 服务调用共享 C 后端，不在 JavaScript 中重写 PIC CPU。
- 新增 Web 器件或功能模块必须解耦为独立脚本，自行维护专属逻辑、视图和样式；
  不得把具体模块实现堆入 `app.js`、页面 HTML 或全局样式文件。
- 支持运行、暂停、精确单步、复位、断点、程序跟随 PC，以及寄存器、栈、RAM、
  程序 Flash 和外设数据查看。
- 每颗 MCU 可设置独立 HEX；多颗 MCU 的状态、断点和程序面板按实例 ID 隔离。
- 画布支持鼠标中心缩放、中键四向平移、框选、多选移动和批量删除。
- 器件移动时实时更新坐标；操作按键不得强制切换用户正在观察的程序页签。
- 器件属性属于具体实例，不把 HEX、容量等属性做成页面全局设置。
- 数据查看和高频状态更新应节流，避免闪烁、卡顿和无意义重绘。
- 修改 UI 后必须实际启动 Web，并使用浏览器检查布局、交互和数据，不能只做
  JavaScript 语法检查。
- Web 测试结束后必须停止本次测试启动的 Node 服务及相关后台进程，并确认默认
  端口 `4173` 已释放。终止前核对端口、命令行和工作目录，只清理本次测试创建
  的服务，不得误杀用户自行启动的进程或遗留 `EADDRINUSE` 问题。
