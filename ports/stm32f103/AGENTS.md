# STM32F103 端口规则

- 端口统一位于 `ports/stm32f103/`，不按 C4/C6/C8/CB/CC 重复创建目录。
- 默认引脚映射可使用虚拟 GP0 → PC13，但映射必须集中配置，不得散落写死。
- 所选示例和固件通过构建参数指定，不得固定为 `blink`。
- 日志默认关闭，通过构建参数选择开启；关闭日志不得改变模拟时间。
- 系统时钟通过统一构建参数配置，默认可为 128 MHz，并允许其他受支持频率。
- 时间同步根据实际系统时钟参数计算，不得为某个频率写死校准值。
- 提供命令行编译和 ST-Link 烧录流程，避免要求用户在 WSL 与 Windows GUI 间
  反复切换。
- 仅供 STM32 使用的工具放在 `ports/stm32f103/tools/`。
