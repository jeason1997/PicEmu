# 公共核心与仿真模型规则

本规则适用于 `src/` 中的公共 C 实现。修改对应的 `include/picemu/` 公开接口或
相关测试时，也必须遵守本文件。

## 芯片与固件

- Intel HEX 必须由共享加载器解析并执行，正确区分配置字与程序存储器地址。
- PIC10F200 和 PIC10F202 使用同一 Baseline 12 位核心，程序空间和 RAM 容量由
  器件描述决定。
- 尊重 PIC10 的真实硬件限制，包括两级硬件栈、GP3 仅输入，以及没有中断、
  UART、硬件 SPI 和硬件 PWM。
- 软件模拟 SPI、UART、PWM 等功能时，必须由 PIC 固件正常翻转 GPIO 实现。
- 指令周期和外设时间必须基于 PIC 时钟计算。宿主机频率、日志开关和前端帧率
  不得改变虚拟 PIC 时间。
- 性能优化后必须验证指令语义、周期数和实际时间未发生错误。

## 虚拟器件与电路模型

- 每种虚拟器件拥有独立的头文件和实现文件。
- 新增器件通过注册机制或统一接口接入，避免每增加一种器件就修改包含所有具体
  器件函数的中央头文件。
- 器件容量、颜色、固件路径等实例属性放在器件的 `attrs` 中。
- 外设模型负责实现协议和状态，显示层不得伪造结果。
- W25Q 等存储器查看器必须读取真实 C 器件模型，并在数据变化后及时更新。
