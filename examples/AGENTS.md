# 示例规则

- 所有示例位于 `examples/<示例名>/`，每个示例独立包含 `main.c`、`Makefile`、
  `diagram.json` 和自动生成的 `build/`。
- 示例固件和电路文件不得散落在仓库根目录。
- 电路由 `diagram.json` 描述，不把示例电路写死在 SDL 或 Web 主程序中。
- SDL 与 Web 应尽量共用同一份 `diagram.json`，以及相同的世界坐标、器件尺寸、
  实例属性和连接关系；容量、颜色和固件路径等实例属性放在 `attrs` 中。
- 连线端点必须真实对应器件引脚，线路不得从器件图形下穿过。自定义路径只使用
  水平和垂直线段，拐点自动形成直角，不显示斜线。
- 示例应展示通用接口。例如存储器示例应提供 `w25q_write(address, data, length)`、
  `w25q_read(...)` 等接口，`main()` 只组织业务流程，底层函数不得写死为只能
  处理某个字符串。
- 根据程序空间和 RAM 需求选择型号。PIC10F200 资源不足时可使用 PIC10F202，
  但 Makefile、HEX 编译参数和电路图中的型号必须一致。
- XC8 构建时检查程序空间、RAM 和硬件栈警告，不能只看是否生成 HEX。
- 新增或修改示例后必须实际使用 XC8 构建成功，确认无错误并在该示例的 `build/`
  中生成 `firmware.hex`；未完成此验证时，不得声称示例已经完成。
- 新增示例默认同步实现并验证 Web 端所需的器件渲染、状态传递和交互，除非用户
  明确限定其他平台。
